confeTTI

A submission is a model + runtime recipe that reproduces a fixed full-precision reference's output while generating images as fast as possible on one RTX 5090 (32GB). The fastest recipe that holds the quality floor leads the board.

The race

What you're optimizing

End-to-end wall-clock seconds per generated image at a fixed resolution and step budget, on one RTX 5090. The reference is Qwen-Image-2512 in BF16 (~57.7GB — it does not fit the card). The race: take a frontier model that can't run on a 32GB card, make it run, and make it run fast.

KERNELS

Attention & compute

SageAttention-style, flash / memory-efficient attention, kernel fusion.

COMPILE

Graphs & passes

CUDA graphs, TensorRT, sfast, torch.compile — cut overhead per step.

FIT

Quantization

INT4, NVFP4, GGUF, FP8 — a means to fit 32GB, not the goal itself.

STEPS

Distillation

Fewer-step samplers and distilled variants without collapsing quality.

MEMORY

Offload

Weights, KV, activation offload and memory planning under 32GB.

THROUGHPUT

Batching

Images-per-second under concurrency, not just single-image latency.

The quality floor

Speed is only the race. Fidelity is the gate.

A recipe must reproduce the reference's final image within a perceptual (LPIPS) distance tolerance on fixed (prompt, seed) probes. A recipe that trades quality for speed — skipped steps, collapsed output — fails the gate regardless of how fast it is.

The gate compares final images, not per-step predictions. That's what lets the competition reward distillation alongside quantization — a distilled 4-step model reaches a perceptually close image even though its per-step path differs. Output-fidelity accepts both legitimate speed levers while still rejecting collapsed recipes.

Eval

Cheap, deterministic, same-box

GATE

Per-step velocity distance

Each submission's predictions are compared to the reference over the public (prompt, seed) corpus. ~2s per probe, so N=1000+ probes per submission is cheap.

RACE

Wall-clock per image

Seconds per image at fixed resolution and steps, measured on the same RTX 5090 for every submission — no cross-box variance.

GUARD

Two-sided speed check

Implausibly-fast and underclaiming runs are both rejected. The number is what the box actually produced.
